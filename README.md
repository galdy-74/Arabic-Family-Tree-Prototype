# برنامج شجرة العائلة الاحترافي — Phase 1

نموذج أولي لواجهة المستخدم في ملف HTML واحد:
- عربي بالكامل مع اتجاه RTL
- بيانات وهمية للعرض فقط
- دون أي منطق أعمال حقيقي

## التشغيل
افتح `index.html` مباشرة في أي متصفح حديث (Chrome / Edge / Firefox).
لا يحتاج خادمًا ولا أدوات بناء.

## النطاق
- ✅ تصميم النافذة الرئيسية كاملًا (قوائم، أدوات، ثلاث لوحات، شريط حالة)
- ✅ طبقة `DataService` وهمية جاهزة للاستبدال لاحقًا
- ❌ لا يوجد حفظ/بحث/حذف فعلي — يُنفَّذ في المراحل اللاحقة

## خارطة الطريق
1. **المرحلة الحالية**: واجهة فقط + بيانات وهمية
2. دمج المكونات في مشروع شجرة العائلة الرئيسي
3. Electron + SQLite (هدف التشغيل: Windows 7)
